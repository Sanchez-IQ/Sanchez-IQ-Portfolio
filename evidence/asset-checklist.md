# Portfolio Asset Checklist

Use this checklist when adding new evidence to the repository.

## Web3 / Digital

- [ ] Published X/Twitter threads
- [ ] Educational posts
- [ ] Community announcements
- [ ] Campaign creatives
- [ ] AMA / Space materials
- [ ] Community-growth screenshots or reports
- [ ] Relevant project links

## Geology

- [ ] Amasiri research PDF
- [ ] Geological maps
- [ ] Field photographs
- [ ] Sample photographs
- [ ] Laboratory tables
- [ ] Porosity/permeability results
- [ ] Research figures
- [ ] Final project presentation

## Professional

- [ ] Web3 CV
- [ ] Geology / Energy CV
- [ ] Mining CV
- [ ] Environmental / Water / Geotechnical CV
- [ ] Sales / Customer Service CV
- [ ] Certificates suitable for public sharing

## Quality Control Before Publishing

- [ ] Confirm the file is mine to publish or I have permission to publish it.
- [ ] Remove personal or confidential information that should not be public.
- [ ] Remove passwords, API keys, tokens and private credentials.
- [ ] Verify names, dates, figures and project claims.
- [ ] Prefer original/source documents for technical claims.
- [ ] Use descriptive filenames.
- [ ] Add a short README or description explaining the asset.

## Recommended Naming Style

Use clear names such as:

`amasiri-geological-research-project.pdf`

`amasiri-field-mapping.jpg`

`stafi-community-growth-case-study.md`

`web3-content-sample-01.md`

`geology-energy-cv.pdf`
