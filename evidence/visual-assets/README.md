# Amasiri Visual Evidence

This directory is reserved for visual assets from the original Amasiri research project.

## Planned Assets

- Study-area / location map
- Accessibility map
- Drainage map
- Geological map
- Sample-location map
- Field photographs
- Outcrop photographs
- Sample photographs
- Research charts and figures

## Source Integrity

Visuals should be taken from the original research document or recreated from its underlying data without changing the reported findings.

When an asset is added, its filename should identify what it represents and, where practical, the source figure/table number should be recorded in the accompanying description.

## Recommended Naming

```text
amasiri-location-map.png
amasiri-geological-map.png
amasiri-sample-location-map.png
amasiri-fieldwork-photo-01.jpg
amasiri-sample-photo-bed1.jpg
amasiri-porosity-permeability-chart.png
```

## Publication Checklist

- [ ] Confirm the visual belongs to the research project or is cleared for public use.
- [ ] Preserve labels and geological terminology from the source.
- [ ] Do not alter numerical results.
- [ ] Keep the original figure/table reference where applicable.
- [ ] Remove unrelated private information before publication.
- [ ] Add a short caption explaining the visual.
